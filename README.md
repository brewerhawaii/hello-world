# TORUS by VINOVA – Phase 1 MVP Scaffold

Production-oriented multi-tenant kiosk platform scaffold for Android, NestJS backend, and React admin portal.

## Project Structure

- `android-kiosk/` Kotlin + Jetpack Compose kiosk app scaffolds
- `backend/` NestJS module scaffolds + API contracts
- `admin-portal/` React + TypeScript + Tailwind admin stubs
- `prisma/` Prisma schema for PostgreSQL
- `seed/` Seed data for VINOVA services/products/memberships
- `docs/` Architecture, routes, analytics, roadmap, and device lock mode notes

## Phase 1 Priorities

1. Reliable kiosk flow with inactivity reset
2. Rule-first recommendations with AI explanation layer
3. Membership, booking, cart, lead capture conversion funnel
4. Tenant/location isolation and RBAC
5. Analytics and auditability
